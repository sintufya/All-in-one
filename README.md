# Kudrop – WhatsApp Dropshipping in 1 Tap

A mobile app that turns WhatsApp into a mini-shop for African resellers.

## Features
- 📸 Auto-generate product catalogs from photos
- 💬 One-tap WhatsApp status posts with optimized captions
- 💰 Payment tracking (M-Pesa/Airtel)
- 📦 Order management & delivery tracking
- 🏆 Leaderboard with cash prizes
- 🔄 Resell mode: mark up & share supplier products

## Tech Stack
- **Frontend**: React Native (iOS/Android)
- **Backend**: Python (Flask/FastAPI)
- **Database**: PostgreSQL
- **Payments**: M-Pesa/Airtel Money API
